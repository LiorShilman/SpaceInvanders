# Invaders: Nexus — Game Plan

תוכנית הפיתוח המלאה (חזון, ארכיטקטורה, שפה חזותית, מפת דרכים) נמצאת ב:

- **גרסה מעוצבת (HTML):** [`docs/game-plan.html`](./game-plan.html) — פתחו בדפדפן מקומית
- **גרסה חיה מתעדכנת:** https://claude.ai/code/artifact/1c36d3c1-ba6d-4dd7-b015-771b1cc7f098

## תמצית

- **פלטפורמה:** דפדפן — Three.js + React Three Fiber, Vite
- **מולטיפלייר:** Colyseus, מתחילים ב-Co-op הישרדותי ובונים PvP א-סימטרי כשכבה שנייה
- **שפה חזותית:** ספינה ירוקה (פוספור) מול אויבים באנרגיה אדומה-מגנטה — ניגוד משלים חזק, מודלים תלת-ממדיים אמיתיים עם חומרים מוצללים (לא צבע שטוח), נבולה פרוצדורלית ברקע. יש גם מצב תלת-ממד אנאגליפי אמיתי (משקפי אדום-cyan), מקש 3.

## מפת דרכים

| שלב | שם | תוכן |
|---|---|---|
| 0 | Foundation | שלד מונורפו, לולאת משחק, HUD, גלים מתקדמים עם קושי עולה, מגני הגנה |
| 1 | Co-op Network | שרת Colyseus, 2-4 שחקנים, revive |
| 2 | Content & Bosses | אויבים מגוונים (Diver/Flanker), בוסים, שדרוגי נשק |
| 3 | Asymmetric PvP | מצב "מפקד פולשים" מול מגינים |
| 4 | Launch Polish | leaderboard, סקינים, פריסה לשרת הבית |

**מצב נוכחי:** Phase 0 מבוסס היטב — משחק אינסופי עם גלים מסלימים (כל גל שנבלם מוליד גל קשה יותר: פורמציה מהירה יותר, אש תכופה יותר), 40 אויבים בפיזור אורגני, 4 מגני הגנה הרסים, ומודלים תלת-ממדיים מפורטים. ראו [`client/`](../client).
