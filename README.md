# Invaders: Nexus

Space Invaders מחדש: תלת-ממדי, מולטיפלייר, בדפדפן. תוכנית הפיתוח המלאה נמצאת ב-[`docs/GAME_PLAN.md`](./docs/GAME_PLAN.md) (וב-[`docs/game-plan.html`](./docs/game-plan.html) לגרסה המעוצבת).

**חי ברשת הבית:** https://shilmanlior2608.ddns.net:38000/SpaceInvanders/

## מצב נוכחי: Phase 0 — משחק סינגלפלייר אינסופי

גלים מסלימים ללא הגבלה (כל גל שנבלם מוליד גל קשה יותר וגם צורת פורמציה שונה — בלוק, טריז, יהלום, שני אשכולות, טבעת), 40 אויבים בפיזור אורגני, 4 מגני הגנה הרסים, מודלים תלת-ממדיים מפורטים, טייס אמיתי בשלושה צירים, וכוונת נעילה. יש גם מצב תלת-ממד אנאגליפי אמיתי (מקש 3). אין עדיין רשת/מולטיפלייר (זה Phase 1).

**התקדמות ותגמול:** 3 חיים לריצה (איבוד כל הכוח מכניס חיסון זמני וחוזר לאותו גל, לא מסיים את הריצה), מכפיל ניקוד על הריגות רצופות (עד x4), ופריטים שנופלים מאויבים שנהרגים — צריך לתפוס אותם בטיסה: משקה בריאות או נשק זמני (פיזור משולש / אש מהירה).

## הרצה (פיתוח)

```bash
npm install
npm run dev
```

יפתח שרת פיתוח בכתובת http://localhost:5173.

**שליטה:** WASD / חצים לתנועה, Z/C לקדימה/אחורה, רווח לירי, 3 להחלפת מצב תלת-ממד (משקפי אדום-כחול).

## פריסה (production)

מוגש דרך IIS כאתר סטטי ב-`/SpaceInvanders` תחת Default Web Site (אותה תבנית כמו FinanceVisual/Photo2Print/RiseUp — ר' `client/public/web.config`). לעדכן את הגרסה החיה:

```bash
npm run build
```

זהו — ה-IIS Application מצביע ישירות ל-`client/dist`, אין שלב העתקה נפרד.

